# Ігротека

Вебсервіс бібліотеки настільних ігор на Symfony 7.4. Відвідувачі переглядають ігри за назвою, категорією, кількістю гравців і тривалістю партії. Адміністратор редагує каталог у EasyAdmin. Для демонстрації є шість вигаданих ігор у трьох категоріях.

## Запуск

Потрібні PHP 8.3 з розширеннями `pdo_sqlite`, `intl`, `mbstring` і XML, Composer 2 та Symfony CLI. Для консольного клієнта потрібен Python 3.8+. Усі команди виконуйте в корені клонованого репозиторію.

1. Встановіть залежності та створіть локальний секрет застосунку. Якщо вже маєте власний `.env.local`, переконайтеся, що в ньому задано `APP_SECRET`.

   ```sh
   composer install
   php -r "file_exists('.env.local') || file_put_contents('.env.local', 'APP_SECRET='.bin2hex(random_bytes(32)).PHP_EOL);"
   ```

2. Створіть таблиці міграцією та заповніть каталог. SQLite зберігає локальну базу в `var/catalog_dev.db`. Повторний запуск команди наповнення пропускає наявні назви.

   ```sh
   php bin/console doctrine:migrations:migrate --no-interaction
   php bin/console app:seed-catalog
   ```

3. Створіть адміністратора зі своєю адресою. Команда приховано запитає пароль і збереже його хеш у локальній базі.

   ```sh
   php bin/console app:create-admin admin@example.test
   ```

4. Запустіть сервер і відкрийте [каталог](http://127.0.0.1:8000/) або [адмінку](http://127.0.0.1:8000/admin).

   ```sh
   symfony serve --no-tls --port=8000
   ```

   Без Symfony CLI для локальної демонстрації підійде `php -S 127.0.0.1:8000 -t public`.

## Дані та маршрути

`Category.games` — колекція ігор (OneToMany). Кожна `Game` має одну обов’язкову категорію (ManyToOne). Категорію з іграми можна видалити після перенесення або видалення її ігор. Сутність `User` створено через `make:user`. Symfony Security перевіряє форму входу, CSRF-токен і право `ROLE_ADMIN` для всього розділу `/admin`.

| Метод і шлях | Результат |
| --- | --- |
| `GET /` | Каталог на Twig |
| `GET /games/{id}` | Картка гри |
| `GET /api/games` | JSON-масив ігор, відсортованих за назвою |
| `GET /api/games/{id}` | JSON-об’єкт гри або HTTP 404 для відсутнього номера |
| `GET /admin` | Вхід до EasyAdmin, перегляд, додавання, редагування та видалення ігор і категорій |

## Клієнт на Python

Запустіть в іншому терміналі, поки працює сервер. Перша команда показує номери всіх ігор, друга читає одну гру та друкує її опис. Клієнт використовує стандартну бібліотеку Python.

```sh
python client/games.py
python client/games.py 1
python client/games.py --base-url http://127.0.0.1:8080
```

## Перевірка

```sh
php bin/console doctrine:schema:validate
php bin/console lint:twig templates
php bin/console debug:router
```

Для перевірки повного сценарію створіть категорію та гру в адмінці. Перевірте нову гру на головній сторінці й у списку Python-клієнта. Після виходу повторне відкриття `/admin/game` має перенаправити на форму входу.
