# Ігротека

Ігротека — це сайт-каталог настільних ігор на Symfony. На сайті можна відкрити картку гри й подивитися її опис, категорію, тривалість партії та кількість гравців. В адмінці можна додавати, редагувати й видаляти ігри та категорії.

Гра належить до однієї категорії, а в категорії може бути багато ігор. Дані зберігаються в SQLite. Таблиці створює міграція Doctrine.

## Як запустити

Потрібні PHP 8.3 з розширеннями `pdo_sqlite`, `intl`, `mbstring` та XML, а також Composer. Команди запускайте в папці проєкту, де лежить `composer.json`.

1. Встановіть залежності та створіть локальний ключ Symfony. Якщо `.env.local` уже існує, команда залишить файл як є.

   ```sh
   composer install
   php -r "file_exists('.env.local') || file_put_contents('.env.local', 'APP_SECRET='.bin2hex(random_bytes(32)).PHP_EOL);"
   ```

2. Створіть таблиці й додайте ігри для прикладу.

   ```sh
   php bin/console doctrine:migrations:migrate --no-interaction
   php bin/console app:seed-catalog
   ```

3. Створіть адміністратора. Замість `admin@example.test` можна вказати свою адресу. Пароль введіть, коли його попросить команда.

   ```sh
   php bin/console app:create-admin admin@example.test
   ```

4. Запустіть сайт.

   ```sh
   symfony serve --no-tls --port=8000
   ```

   Якщо Symfony CLI не встановлено, запустіть `php -S 127.0.0.1:8000 -t public`.

   Відкрийте [каталог](http://127.0.0.1:8000/) або [адмінку](http://127.0.0.1:8000/admin). Для входу використайте адресу й пароль із кроку 3.

## API та Python

Запит до `/api/games` повертає всі ігри у форматі JSON. Запит до `/api/games/1` повертає гру з номером 1. Її сторінка на сайті відкривається за адресою `/games/1`.

Поки сайт працює, відкрийте другий термінал у папці проєкту. Перша команда покаже список ігор, друга — гру з номером 1 та її опис. Достатньо встановленого Python.

```sh
python client/games.py
python client/games.py 1
```

Файл `.env.local`, локальна база в `var/` і папка `vendor/` ігноруються Git. Пароль адміністратора зберігається в базі як хеш.
